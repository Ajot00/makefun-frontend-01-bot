# Lightboard

A compact, static make.fun frontend for the public bounty board, bounty details, standings, and public profiles. It keeps the editorial black and pink palette, places the active bounty beside the board, and loads each view from make.fun's public API.

Serve `app/` as the web root. The app uses native browser modules and needs no build step. `main.ts` packages the app and the three screenshots into the kit dossier. API access is read-only.
